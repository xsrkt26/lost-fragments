# Lost Fragments v0.1.5

对比基准：`v0.1.3` -> `v0.1.5`

本版重点是 Hub 到局内游戏的无缝过渡、书页式 UI 重构、背包网格表现、物品/工具/饰品经济数据扩展，以及剧情系统骨架接入。`v0.1.4` 已存在为中间标签，本次继续发布为 `v0.1.5`。

## 主要更新

### Hub 与局内游戏过渡

- Hub 点击捕梦网后不再跳转到单独 Battle 场景，而是在 `hub_scene.tscn` 内打开 `HubBattleLayer`，运行时创建并管理 `BattleManager`。
- 局内结束时会持久化背包状态并清理 Hub 内临时战斗节点，保证返回 Hub 后数据连续。
- Hub 到局内的聚焦动画改为围绕场景内已有捕梦网触发，不再额外生成捕梦网节点。
- 过渡动画改为硬纸板图层缩放与裁剪，保留虚拟视窗四角固定，减少整屏缩放造成的错位和遮挡。
- 修正硬纸板角标、书页裁剪、Hub 结构合并后的兼容问题，并保留进入局内的 Intro 动画。
- 恢复默认视口分辨率，修复多处书页压缩/转场的布局警告和内容溢出。

### 书页与静态 UI 管理

- 新增 `BookPageNavigator` 的书页栈、压缩、切页与回退管理，支持 Hub 内书页式页面切换。
- 新增/重构 `BookBackground`、`BookBackgroundConfig`，统一书页背景、标签页和页面视觉根节点布局。
- 新增 `BackpackPage` 场景，背包页拥有独立的静态摆放内容、背包 UI、统计纸张、丢弃区域和运行摘要。
- 调整背包页统计纸张、垃圾桶图标、文字标签位置，减少书页内元素错位。
- 图鉴、设置、商店、事件、主游戏 UI 等页面接入新的书页/Hub 布局约束。

### 背包网格与根源之梦

- 背包 UI 使用场景内静态 7x7 格子，不再依赖运行时生成格子节点。
- 每个格子新增静态 `LockedCellPin` 子节点，锁定、未解锁或临时阻塞格会显示图钉占位符。
- 新增 `assets/ui/backpack/locked_cell_pin.png` 作为不可用格占位贴图。
- 根源之梦初始位置不再硬编码，开局时按当前背包可用区域扫描第一个可摆放位置。
- 老存档缺少根源之梦时，也会使用同一套“第一个可摆放位置”逻辑补回。
- `BackpackManager.find_available_pos()` 扫描时静音放置拒绝日志，避免正常寻位刷屏。
- 修复局内背包贴图和实际网格像素级对齐相关问题，并替换背包展开动画最后一帧白边素材。

### 局内 Intro 与交互

- `MainGameUI` 增加背包落下、5 帧背包展开、左侧 UI 入场、网格显现的 Intro 流程。
- Intro 阶段会锁定不应响应的抽取/结束/取消输入，结束后进入可交互状态。
- 支持嵌入式战斗关闭回调，方便 Hub 内原地运行局内游戏。
- 结算前会统一丢弃背包外物品并持久化背包，降低跨场景状态丢失风险。
- 局内布局使用固定设计尺寸适配视口，减少不同分辨率下元素漂移。

### 物品、工具、饰品与经济

- 新增 `ItemDrawPool`，按当前 Act、可抽取状态、类别、格子数、权重和标签构建物品抽取池。
- 新增 `ToolDrawPool`，按 Act、工具可用性、已有工具数量和稀有度控制工具出现。
- 44 个物品已接入图标资源，包含通用、机械、梦境之种、污染等分类。
- 15 个工具写入 `data/tools/tools.json`，并接入奖励和商店候选池。
- 56 个饰品数据更新，补充价格、稀有度、标签和后续权重使用基础。
- 商店现在支持物品、饰品、工具混合生成，支持刷新消耗、购买缓存、已购排除和回收券折扣。
- 奖励生成器接入阶段权重、构筑标签、物品/饰品/工具类型权重。
- 礼物盒效果改为通过物品抽取池按格子数生成物品，避免生成逻辑和主抽取池分叉。
- 新增 `data/economy/economy.json`，集中维护战斗奖励、商店刷新成本、价格倍率和出售价值。

### 路线、关卡与成长框架

- 路线扩展为 6 幕：浅层梦境、污迹梦境、萌芽梦境、齿轮梦境、裂隙梦境、终局梦境。
- 每幕包含战斗、商店、事件和 Boss 战节点；Boss 分数目标分别为 45、65、85、110、135、165。
- `StageConfig` 接入每幕视觉、BGM、捕梦网贴图、局内修正、Boss 机制、奖励权重和商店权重。
- 后期 Act 支持抽取梦值成本增加、污染压力和阻塞格配置。
- `RunManager` 增加当前商店状态、待处理物品奖励、工具状态、临时/永久背包锁格、路线进度和随机源的保存恢复。

### 剧情系统骨架

- `StoryManager` 默认启用，加载剧情 JSON，并监听 `run_started`、`route_changed`、`run_finished`。
- 进入每幕首节点时会尝试排队 `enter_stage_N` / `进入场景N` 和固定事件序列。
- 固定事件序列按 Act 映射到小咪、小舅、姥姥、父母、小佳、拾忆。
- 胜利/失败结局会进入 `end1`、`end2`、`end3` 分支。
- 支持 cutscene 类型剧情进入 `CutsceneScene`，普通剧情在 Hub/Battle 上叠加 `DialogueOverlay`。
- 剧情队列支持当前剧情播放中排队、Hub 场景可用后补放、切场景完成后触发。
- `CutsceneScene` 完成后，非结局剧情会回到 Hub。

### 资源与文档

- 新增 `AssetPaths` 统一管理核心资源路径、贴图加载和路径校验。
- 新增商人动画 MOV 源文件、图钉压缩包、毛绒/物品源包等源素材；当前商人 MOV 作为源资产保留，尚未运行时接入。
- 移除大量不应运行时携带的 `.import` 源素材噪声，补充 runtime 使用的物品图标资源。
- 新增物品、机械物品、梦境之种、污染物品、饰品和经济系统设计文档。
- 更新 AI 架构/资源管理文档、玩法循环、路线、道具、饰品和实现 TODO。

### 测试与质量

- 新增 `test_asset_paths.gd`、`test_item_draw_pool.gd` 等测试，覆盖资源路径、抽取池、阶段配置和商店/奖励逻辑。
- 更新 Hub、书页、背包、商店、战斗、旋转、丢弃、经济、关卡和工具相关测试。
- 本地验证记录：GUT 全量 `275/275 passed`，`2662 asserts`。
- Release workflow 会在标签推送后重新运行 GUT、严格场景 smoke 测试、Windows 导出和打包。

## 修复

- 修复 Hub 硬纸板四角和裁剪范围错位。
- 修复书页切换时内容溢出、压缩层级遮挡和布局警告。
- 修复 Hub 到局内过渡中 Intro 动画丢失的问题。
- 修复战斗背包贴图网格与实际交互网格错位。
- 修复脱离场景树测试环境中的 root/autoload 查找问题。
- 修复背包展开帧素材白边问题。
- 修复未解锁/阻塞背包格缺少清晰占位符的问题。
