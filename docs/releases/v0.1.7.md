# Lost Fragments v0.1.7

对比基准：`v0.1.6` -> `v0.1.7`

本版重点补齐 Hub 到战斗、商店、故事书页、图鉴、主菜单快捷入口、Hub 对话气泡和背包持久化相关体验，同时强化发布前检查与资源导出稳定性。

## 更新内容

### Hub、战斗与商店流程

- Hub 交互流程拆分为战斗、商人、玩家、交互流和布局控制器，降低 `hub_scene.gd` 的直接职责。
- 接入 Hub 商店入场动画资源与控制器，商店进入、背包出售和商品展示流程更完整。
- Hub 进入战斗时新增捕梦网下方毛绒云朵帧动画，播放顺序为 `plush_transition_01` 到 `plush_transition_04`，并与右侧背包展开动画同步。
- 新增 Hub 对话气泡视觉控制器与小咪分层素材，Hub 内故事对白可在角色锚点附近以气泡方式播放。
- 优化 Hub 内嵌战斗层与捕梦网交互状态，战斗开始、结束和返回 Hub 时会重置对应视觉状态。
- 新增工具栏、待领取物品和背包出售相关 presenter，减少战斗、背包、商店界面之间的重复 UI 逻辑。

### 背包与存档修复

- 修复 `root_dream` 初始/恢复位置，避免根源之梦在背包恢复时落到错误位置或被阻塞格影响。
- 背包恢复逻辑会尝试修复必需物品位置；缺失或旧数据项会给出 warning 并跳过，降低坏档导致流程中断的风险。
- 存档和 Run 持久化 codec 增强，对背包尺寸、工具、饰品、路线、事件、商店购买状态和故事播放状态的恢复更稳。
- 商店商品缓存会过滤已购买项，刷新商品和购买状态记录更一致。

### 故事书页、主菜单与图鉴

- 新增故事书页流程和 `story_book_page` 场景，支持从主菜单书页导航进入故事内容。
- 主菜单入口和故事文本排版更新，继续游戏、新游戏、图鉴、设置等入口布局更稳定。
- 发布版启用主菜单快捷键，便于 release 包快速进入关键页面和验证流程。
- 图鉴滚动和网格视觉重做，新增图鉴网格背景与框体绘制逻辑，减少滚动边界和遮挡问题。

### 适配、性能与反馈

- 新增 UI 设计缩放工具，多个主界面、Hub、背包、商店、设置、事件和故事场景适配 1920x1080 与全屏显示。
- 场景切换缓存和反馈文本池优化，减少重复加载与频繁创建 UI 节点的开销。
- 音频管理器增加 stream 缓存，降低重复播放 BGM/SFX 时的资源加载成本。
- 数据库加载器对缺失资源、重复数据和异常配置的容错更强。

### 发布与测试

- GitHub Actions 的 GUT workflow 增加 Godot export templates 缓存、Python 工具测试、严格 warning 检查和 Windows 导出烟测。
- Release workflow 增加 Python 工具测试，并将严格场景 smoke 调整为 engine warning 也会失败。
- 导出 preset 排除 `.godot`、`.tmp` 等本地缓存目录，减少把开发缓存打入发布包的风险。
- 场景 smoke 脚本和导出脚本增强失败处理，发布前更容易定位场景加载、导入和导出问题。
- 新增/更新测试覆盖：数据加载容错、存档管理、Run 持久化契约、背包持久化、图鉴场景、主菜单场景、UI 反馈和卡牌 tooltip。
