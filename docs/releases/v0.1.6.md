# Lost Fragments v0.1.6

对比基准：`v0.1.5` -> `v0.1.6`

本版用于快速验证发布包启动窗口行为，重点修复发布版默认进入全屏 1080P 的问题。

## 更新内容

- 发布版默认窗口模式显式设置为 `Windowed`。
- 项目默认视口保持 `1280x720`，并在 `project.godot` 中写入 `window/size/mode=0`，避免导出包启动阶段落入全屏模式。
- `SettingsManager` 增加显示设置版本号 `DISPLAY_SETTINGS_VERSION = 2`。
- 旧版本保存过的显示设置会迁移：如果用户本地存在旧 `settings.cfg`，例如 `fullscreen + 1920x1080`，首次启动新版会重置为 `windowed + 1280x720`。
- 设置页之后仍可手动切换全屏或更高分辨率，保存后的新版本设置不会被重复重置。
- `reset_to_defaults()` 统一使用默认显示设置工厂，默认值固定为窗口模式和 720P。
- 增加设置迁移测试，覆盖旧全屏 1080P 配置迁移到窗口 720P。
- UI 字体管理改为直接 preload 当前项目字体资源，减少运行时路径查找分支。

## 验证

- 本地 GUT 全量通过：`276/276 passed`，`2666 asserts`。
- Release workflow 会在标签推送后再次执行 GUT、严格场景 smoke、Windows 导出、打包和 GitHub Release 创建。
