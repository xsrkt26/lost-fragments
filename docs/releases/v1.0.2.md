# Lost Fragments v1.0.2

This Windows release fixes ornament rune icons in exported release builds.

## Changes

- Fixed ornament icon loading in release exports where Godot exposes imported textures through `.png.import` entries instead of source `.png` files.
- Kept the fallback text behavior for genuinely missing ornament icons.
- Updated the Windows release executable metadata to `1.0.2`.

## Validation

- Verified the Windows export package contains imported rune textures and `.png.import` metadata.
- Targeted ornament icon logic test added for exported import entries.
