# Source Image Area

This directory is for source deliveries, reference images, videos, archives, and audit material.

Do not reference files here from runtime code, scenes, resources, or data. Copy selected assets into the correct runtime directory under `assets/ui/`, `assets/characters/`, `assets/audio/`, or `assets/fonts/` first.

Godot ignores this directory through `.gdignore`; release exports also exclude it.
