# 物品随机抽取与投放机制

## 一、设计目标

本机制用于决定玩家每次捕梦时抽取到什么物品。

需要解决的问题：

1. 第一层不能把全部物品一次性放入池子，玩家应先理解基础通用物品。
2. 后续每过一层，逐步把污染、梦境之种、机械、道具等内容加入捕梦池。
3. 随着物品总数增加，玩家不应因为池子变大而很难抽到自己正在构筑的流派。
4. 商店从中期开始提供“降低某些类别抽取概率”的服务，让玩家可以付费收窄捕梦方向。
5. 抽取公式必须能计算期望，方便后续调数和测试。

本机制采用三段式抽取：

1. 先判断本次捕梦是否抽到道具。
2. 如果不是道具，再抽取大类别：通用、污染、梦境之种、机械。
3. 在大类别内，先抽取定位，再抽具体物品。

这样做的核心原因是：物品数量增加时，不能让“某个流派的总出现率”被具体物品数量自然稀释。玩家需要的是先稳定抽到某个构筑方向，再在该方向内接受具体物品的随机性。



## 二、基础分类

### 1. 抽取类别

捕梦抽取使用以下 5 个抽取类别：

| 抽取类别 | 说明 | 是否作为主流派 |
| --- | --- | --- |
| 通用 | 不强制玩家进入特定流派，提供基础分数、梦值、丢弃、撞击启动和过渡能力。 | 否 |
| 污染 | 围绕污染层数、废弃物、净化和污染额外结算。 | 是 |
| 梦境之种 | 围绕播种、梦境之种等级成长和大型梦种终端。 | 是 |
| 机械 | 围绕机械标签、普通传导、机械撞击和曲线传动。 | 是 |
| 道具 | 一次性消耗物，不参与普通背包撞击结算。 | 否 |

污染、梦境之种、机械是三个主要流派。通用物品是构筑润滑和早期教学内容。道具是低比例的主动修正资源，不能和主流派使用同一套概率期望。

### 2. 抽取类别与标签分离

物品标签用于结算联动，抽取类别用于投放概率。二者不能混用。

例如：

| 物品 | 标签 | 抽取类别 | 原因 |
| --- | --- | --- | --- |
| 垃圾回收器 | 机械 | 污染 | 这是污染净化终端，不应因为机械概率提高而大量出现。 |
| 生锈齿轮 | 废弃物/机械 | 污染 | 这是污染扩散物品，主要服务污染流。 |
| 根系导管 | 机械/梦之种 | 梦境之种 | 这是梦种升级工具，机械标签只用于联动。 |
| 温室灯 | 机械/梦之种 | 梦境之种 | 这是梦种纵向成长核心。 |
| 黑墨滴 | 道具 | 道具 | 即使它服务污染，也应先归入道具总概率。 |

实现时建议为每个可抽取物品增加一个单独字段：

`drop_category`

该字段只允许取值：

`general`、`pollution`、`dream_seed`、`mechanical`、`tool`



## 三、分层投放

### 1. 投放原则

每层新增物品按以下原则投放：

1. 第一层只投放少量通用物品。
2. 第二层同时打开三个主流派的启动件，让玩家开始看见方向。
3. 第三层加入流派稳定件和中期核心。
4. 第四层加入大部分核心件和稀有饰品对应的构筑需求。
5. 第五层加入高消耗终端和后期补强。
6. 第六层原则上不大量新增新规则，只补齐后期池子，让已经成型的构筑继续拿到可用物品。

### 2. 推荐解锁表

不可抽取物品不进入捕梦池，例如根源之梦、苹果核、梦境之种基础形态。它们通过初始配置、生成、播种或其他效果出现。

| 层数 | 通用 | 污染 | 梦境之种 | 机械 | 道具 |
| --- | --- | --- | --- | --- | --- |
| 第1层 | 棒球、破旧闹钟、易拉罐、矿泉水瓶、苹果 | 不开放 | 不开放 | 不开放 | 首个捕梦关卡不开放；第2个捕梦关卡与第1个商店起开放小补丁、梦值糖、转向螺丝、破弹珠、小水滴 |
| 第2层 | 裂痕镜片、礼物盒 | 纸团、joker、便利贴、漏水钢笔 | 梦土铲、小喷壶、空心果壳、种子铃铛 | 铁珠、小齿轮、传动皮带 | 黑墨滴、消毒喷雾、肥料包、延长钩、苹果蜡 |
| 第3层 | 美味烧鸡 | 伤心泰迪熊、小药瓶、垃圾袋、旧足球 | 月露灯、育苗托盘、根系导管、嫁接刀 | 左传动弯管、右传动弯管、制动片、齿条 | 腐蚀酸、快速发芽剂、传动油、回收夹 |
| 第4层 | 保险契约 | 过期药物、针管、剩饭盒、潮湿纸箱 | 温室灯、蔓生罗盘、生态瓶、根网枢纽 | 差速器、双轴转轮、蓄能飞轮、曲轴、计数轮 | 空白符纸 |
| 第5层 | 无新增 | 垃圾回收器、生锈齿轮 | 月冠温床、星根祭坛、巨木回声 | 中央引擎、终端计算机、星环轴承 | 无新增 |
| 第6层 | 无新增 | 无新增 | 无新增 | 无新增 | 无新增 |

如果道具系统暂缓实现，则所有道具投放概率视为 0，并把道具概率重新分配给非道具类别。



## 四、抽取概率公式

### 1. 道具独立概率

道具不直接参与主流派竞争。每次捕梦先进行一次道具判定。

记：

- `L`：当前层数。
- `T(L)`：当前层道具基础概率。
- `s_tool`：商店购买的道具抑制等级。
- `T'(L)`：实际道具概率。

当前实现采用固定低比例，并用路线节点屏蔽第一关。推荐基础值：

| 位置 | `T(L)` |
| --- | ---: |
| 第1层第1个捕梦关卡 | 0% |
| 第1层第2个捕梦关卡起 | 15% |
| 第2-6层 | 15% |

第1层第1个商店已经可以售卖已解锁道具；商店与捕梦都必须按 `earliest_act <= 当前层` 过滤，不能出现未来层道具。

道具抑制公式：

`T'(L) = T(L) x 0.5 ^ s_tool`

当前建议 `s_tool` 最大为 1。

如果道具系统未启用：

`T'(L) = 0`

### 2. 非道具大类别概率

如果本次捕梦没有抽到道具，则在通用、污染、梦境之种、机械中抽取一个类别。

记：

- `C = {通用, 污染, 梦境之种, 机械}`。
- `B_c(L)`：第 `L` 层类别 `c` 的基础权重。
- `m_c`：商店抑制后的类别倍率。
- `R_c(L)`：类别 `c` 的实际权重。
- `P_c(L)`：本次捕梦最终抽到类别 `c` 的概率。

推荐基础权重如下。该权重是在“没有抽到道具”的条件下使用的条件概率。

| 层数 | 通用 | 污染 | 梦境之种 | 机械 |
| --- | ---: | ---: | ---: | ---: |
| 第1层 | 100% | 0% | 0% | 0% |
| 第2层 | 40% | 20% | 20% | 20% |
| 第3层 | 28% | 24% | 24% | 24% |
| 第4层 | 22% | 26% | 26% | 26% |
| 第5层 | 18% | 27.33% | 27.33% | 27.33% |
| 第6层 | 15% | 28.33% | 28.33% | 28.33% |

类别抑制倍率：

| 类别 | 最大抑制等级 | 每级倍率 |
| --- | ---: | ---: |
| 污染 | 2 | x0.5 |
| 梦境之种 | 2 | x0.5 |
| 机械 | 2 | x0.5 |
| 通用 | 1 | x0.7 |

公式：

`R_c(L) = B_c(L) x m_c`

`P_c(L) = (1 - T'(L)) x R_c(L) / sum(R_all(L))`

如果某个类别在当前层没有已解锁物品，则该类别权重视为 0，并重新归一化。

### 3. 类别内定位概率

三个主流派在类别内不直接均匀抽具体物品，而是先抽定位。

主流派定位分为：

| 定位 | 说明 |
| --- | --- |
| 启动/过渡 | 让流派能开始运作，前期出现率较高。 |
| 核心 | 中期构筑骨架，决定流派玩法。 |
| 后期补强 | 高消耗、高上限、需要已有构筑支持。 |

推荐定位权重：

| 层数 | 启动/过渡 | 核心 | 后期补强 |
| --- | ---: | ---: | ---: |
| 第2层 | 70% | 30% | 0% |
| 第3层 | 45% | 45% | 10% |
| 第4层 | 30% | 45% | 25% |
| 第5层 | 25% | 40% | 35% |
| 第6层 | 20% | 40% | 40% |

如果某个定位下当前没有已解锁物品，则在该类别内重新归一化。

具体物品概率：

`P_i = P_c(L) x P_role(c, L) x W_i / sum(W_role_items)`

其中：

- `P_i`：物品 `i` 的最终捕梦概率。
- `P_c(L)`：该物品所属抽取类别的最终概率。
- `P_role(c, L)`：该类别内对应定位的概率。
- `W_i`：物品自身权重。

同一定位内的 `W_i` 默认都为 1。需要强调某些物品时再单独调整。

建议额外使用以下修正：

| 修正 | 公式 | 目的 |
| --- | --- | --- |
| 新物品展示修正 | 新解锁的第一层 `x1.25` | 保证玩家能看见新机制。 |
| 非堆叠重复修正 | 已拥有同名物品时 `x0.75 ^ 拥有数量`，最低 `x0.4` | 避免单局重复过多同名非道具。 |
| 道具堆叠修正 | 未达堆叠上限时不降低，达到上限后 `x0.3` | 道具允许堆叠，但不能无限挤占。 |



## 五、商店概率抑制

### 1. 开放时间

商店从第2层开始可以出现概率抑制服务。

理由：

1. 第一层只投放通用物品，不需要抑制。
2. 第二层玩家第一次看到三个主流派后，可以开始选择不想走的方向。
3. 过早开放会让玩家在不了解流派前做不可逆选择。

### 2. 服务名称与效果

建议商店服务名为“滤梦”。

| 服务 | 开放层 | 效果 | 上限 |
| --- | ---: | --- | --- |
| 降低污染物品出现率 | 第2层 | 污染类别倍率 x0.5 | 2 级 |
| 降低梦境之种物品出现率 | 第2层 | 梦境之种类别倍率 x0.5 | 2 级 |
| 降低机械物品出现率 | 第2层 | 机械类别倍率 x0.5 | 2 级 |
| 降低通用物品出现率 | 第3层 | 通用类别倍率 x0.7 | 1 级 |
| 降低道具出现率 | 第3层，道具系统启用后 | 道具概率 x0.5 | 1 级 |
| 重置一个滤梦效果 | 第3层 | 移除一个类别的全部抑制等级 | 无 |

抑制效果默认持续到整把游戏结束。允许重置是为了避免玩家前期选择后无法转型。

### 3. 推荐价格

当前商店经济未完全定稿，以下只作为初版建议：

| 服务 | 推荐价格 |
| --- | ---: |
| 主流派第1级抑制 | 45 |
| 主流派第2级抑制 | 70 |
| 通用抑制 | 60 |
| 道具抑制 | 40 |
| 重置一个滤梦效果 | 30 |

价格应低于关键饰品，但高于普通一次性道具。它的定位是长期调整概率，而不是直接给强度。

### 4. 道具与流派抑制的关系

主流派抑制不直接改变道具总概率。

例如玩家降低污染物品出现率时：

- 纸团、过期药物、垃圾回收器等污染抽取类别物品会明显减少。
- 黑墨滴、消毒喷雾、腐蚀酸仍然属于道具池，不从道具总概率中移除。

但是为了避免体验割裂，道具池内部可以做轻微同步：

`同主题道具权重 = 原权重 x 0.7 ^ 对应主流派抑制等级`

例如玩家把污染抑制到 2 级，则黑墨滴、消毒喷雾、腐蚀酸在道具池内部权重变为 `0.7 x 0.7 = 0.49`。



## 六、期望计算

### 1. 类别期望

如果玩家在某一层预计进行 `n` 次捕梦，某类别最终概率为 `p`，则：

期望抽到数量：

`E = n x p`

至少抽到 1 个该类别物品的概率：

`Pr(N >= 1) = 1 - (1 - p) ^ n`

至少抽到 `k` 个该类别物品的概率：

`Pr(N >= k) = 1 - sum(x = 0 到 k - 1) [C(n, x) x p ^ x x (1 - p) ^ (n - x)]`

### 2. 第4层示例

假设：

- 道具系统启用。
- 第4层道具概率为 10%。
- 第4层非道具基础权重为：通用 22%，污染 26%，梦境之种 26%，机械 26%。
- 本层预计捕梦 10 次。

未购买滤梦时：

| 类别 | 单次概率 | 10 次期望数量 | 至少 1 个 | 至少 3 个 |
| --- | ---: | ---: | ---: | ---: |
| 任一主流派 | 23.4% | 2.34 | 93.0% | 42.6% |
| 通用 | 19.8% | 1.98 | 89.1% | 31.7% |
| 道具 | 10.0% | 1.00 | 65.1% | 7.0% |

这代表：如果玩家没有主动筛选，第4层每个主流派都能被稳定看见，但不保证能围绕某个流派大量成型。

### 3. 专注机械示例

假设玩家希望走机械流，在商店中把污染和梦境之种都抑制到 2 级。

第4层权重变为：

- 通用：22
- 污染：26 x 0.25 = 6.5
- 梦境之种：26 x 0.25 = 6.5
- 机械：26

归一化后，机械最终概率为：

`90% x 26 / (22 + 6.5 + 6.5 + 26) = 38.4%`

10 次捕梦期望：

| 类别 | 单次概率 | 10 次期望数量 | 至少 1 个 | 至少 3 个 |
| --- | ---: | ---: | ---: | ---: |
| 机械 | 38.4% | 3.84 | 99.2% | 80.5% |

如果玩家还在第3层或第4层购买了通用抑制，则机械概率约为 43.0%，10 次捕梦期望为 4.30 个，至少 3 个机械物品的概率约为 87.7%。

这说明商店滤梦的价值不是保证抽到某个具体物品，而是把某个流派从“能看见”提升到“可以稳定围绕它构筑”。

### 4. 定位期望

仍以第4层机械为例。第4层主流派定位权重为：

- 启动/过渡：30%
- 核心：45%
- 后期补强：25%

未购买滤梦时，机械总概率为 23.4%：

| 定位 | 单次概率 | 10 次期望数量 | 至少 1 个 |
| --- | ---: | ---: | ---: |
| 机械启动/过渡 | 7.0% | 0.70 | 51.7% |
| 机械核心 | 10.5% | 1.05 | 67.1% |
| 机械后期补强 | 5.9% | 0.59 | 45.3% |

购买污染和梦境之种 2 级抑制后，机械总概率为 38.4%：

| 定位 | 单次概率 | 10 次期望数量 | 至少 1 个 |
| --- | ---: | ---: | ---: |
| 机械启动/过渡 | 11.5% | 1.15 | 70.6% |
| 机械核心 | 17.3% | 1.73 | 85.0% |
| 机械后期补强 | 9.6% | 0.96 | 63.5% |

这比直接在 15 个机械物品中均匀随机更稳定。玩家不一定抽到指定的核心物品，但大概率会抽到某个机械核心件。

### 5. 具体物品期望边界

当某个流派已有 10 到 15 个物品时，不应要求玩家必须随机抽到某一个指定物品才能成立。

例如第4层机械已专注后，机械总概率约 38.4%，核心定位概率 45%。如果机械核心池中有 6 个同权重物品，则某个指定核心物品的单次概率约为：

`38.4% x 45% / 6 = 2.88%`

10 次捕梦至少抽到它一次的概率约为 25.3%。

因此设计约束是：

1. 随机捕梦负责提供“流派方向”和“同定位替代件”。
2. 不要让构筑必须依赖某一个指定物品。
3. 如果某个物品是构筑必须件，应放入商店、事件、Boss 奖励、保底奖励或可选择奖励，而不是只依赖捕梦随机。



## 七、梦值消耗期望

每次捕梦实际消耗由两部分组成：

1. 抽到物品的梦值消耗。
2. 当前局内捕梦次数带来的额外消耗。

记：

- `cost_i`：物品 `i` 的梦值消耗。
- `P_i`：物品 `i` 的最终抽取概率。
- `extra(k)`：本局第 `k` 次捕梦的额外消耗。

第 `k` 次捕梦的期望梦值消耗为：

`E_cost(k) = sum(P_i x cost_i) + extra(k)`

如果有饰品或道具降低梦值消耗，则作为后置修正：

`E_final_cost(k) = E_cost(k) - E[梦值减免]`

调数时应检查每层的平均物品梦值消耗：

| 层数 | 平均物品梦值消耗目标 |
| --- | ---: |
| 第1层 | 1-2 |
| 第2层 | 2-4 |
| 第3层 | 4-7 |
| 第4层 | 6-10 |
| 第5层 | 8-12 |
| 第6层 | 8-13 |

如果某一层的平均物品梦值消耗过高，玩家会因为抽到高消耗终端而提前结束局内游戏。优先调整方式：

1. 降低后期补强定位权重。
2. 把高消耗物品推迟一层解锁。
3. 降低该物品在定位内的 `W_i`。
4. 增加同层梦值回复、减消耗或低消耗过渡物品比例。



## 八、实现流程

一次捕梦的推荐流程：

1. 读取当前层数 `L`。
2. 读取当前整把游戏的商店滤梦状态。
3. 生成当前层已解锁且可抽取的物品池。
4. 如果道具系统启用，按 `T'(L)` 判定是否抽道具。
5. 若抽道具，在道具池内按道具权重抽取。
6. 若不抽道具，按通用、污染、梦境之种、机械的调整后权重抽取大类别。
7. 在大类别内抽定位。
8. 在定位内按具体物品权重抽取物品。
9. 生成物品，放到捕梦后预设落点。
10. 按当前局内规则结算梦值消耗、分数和背包效果。

伪代码：

```text
draw_item(layer, run_state):
    unlocked_pool = get_unlocked_drawable_items(layer)

    tool_rate = get_tool_rate(layer, run_state.filters)
    if tools_enabled and random() < tool_rate:
        return weighted_pick_tool(unlocked_pool.tools, run_state.filters)

    category_weights = get_category_weights(layer, run_state.filters)
    category = weighted_pick(category_weights)

    role_weights = get_role_weights(category, layer)
    role = weighted_pick_available_role(role_weights, unlocked_pool[category])

    item_weights = get_item_weights(unlocked_pool[category][role], run_state)
    return weighted_pick(item_weights)
```



## 九、验收标准

本机制落地后，应满足以下标准：

1. 第1层捕梦池只出现指定通用物品。
2. 不可抽取物品不会通过捕梦直接出现。
3. 道具系统未启用时，道具概率为 0，且不会影响其他类别归一化。
4. 三个主流派使用独立类别概率，不会因为某个流派物品数量多而自然占更高概率。
5. 商店滤梦可以稳定降低指定类别的抽取概率，但不会把类别降到绝对 0。
6. 同一流派内先按定位抽取，再按具体物品抽取。
7. 第4层未滤梦时，单个主流派在 10 次捕梦中的期望数量约为 2.3 个。
8. 第4层专注一个流派并抑制另外两个主流派到 2 级时，目标流派在 10 次捕梦中的期望数量约为 3.8 个。
9. 道具在启用后保持低比例，默认 10 次捕梦期望不超过 1 个左右。
10. 任何需要指定物品才能成立的构筑，都不能只依赖捕梦随机获得。
