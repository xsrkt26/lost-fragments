# 经济价值系统 - 2026-05-30

## 目标

商店经济的目标是让玩家进入商店后需要评估：保留背包内物品继续构筑，还是卖掉一半甚至全部物品，换取饰品、道具或关键物品。

本版先统一价值基准与运行数据，售卖 UI 可在后续商店迭代中接入同一套公式。

## 核心规则

| 项目 | 规则 |
| --- | --- |
| 物品买入价 | 使用 `item.price` 作为商店买入基准价 |
| 物品售卖价 | `floor(买入价 / 2)`，最低为 1 |
| 废弃物识别 | 通过 `废弃物` 标签识别，`price` 不再使用负数 |
| 饰品买入价 | 使用 `ornament.price` 作为商店买入基准价 |
| 层数倍率 | 本版取消物品、饰品的额外层数价格倍率 |
| 稀有度倍率 | 本版取消饰品的额外稀有度价格倍率，稀有度已经体现在表内价格 |

## 基准格价

基础格子的买入价定为 `8`，售卖价为 `4`。

推导：

| 指标 | 数值 |
| --- | ---: |
| 初始背包可用空间 | 25 格 |
| 半包参考格数 | 14 格 |
| 14 格基础售卖收入 | 56 |
| 普通饰品基准价 | 38 |
| 1.5 个普通饰品基准价 | 57 |

因此，玩家卖掉约半包前期基础物品，理论上可以购买约 `1.5` 个普通饰品，符合“卖物品换饰品”的商店决策目标。

## 物品定价公式

基础公式：

```text
买入价 = 占格数 x 8 + 投放层补正 + 定位补正 + 效果补正
售卖价 = floor(买入价) / 2)
```

投放层补正：

| 投放层 | 补正 |
| ---: | ---: |
| 1 | 0 |
| 2 | 2 |
| 3 | 4 |
| 4 | 6 |
| 5 | 8 |
| 6 | 10 |

定位补正：

| 定位 | 补正 |
| --- | ---: |
| 启动/过渡 | 0 |
| 核心 | 2 |
| 后期补强 | 5 |

效果补正用于处理明显高上限或特殊保险类物品，通常控制在 `0-5`，避免后期单件物品卖价过度膨胀。

## 饰品定价区间

| 稀有度 | 价格区间 | 说明 |
| --- | ---: | --- |
| 普通 | 36-44 | 早期稳定收益和方向提示 |
| 进阶 | 56-70 | 构筑成型和流派强化 |
| 稀有 | 86-120 | 后期高上限、Boss 或成型补强 |

## 当前投放池期望价值

计算前提：

- 使用当前程序内 `ItemDrawPool` 的大类权重、定位权重、同层展示修正。
- 不计算玩家已有物品导致的重复衰减。
- 不计算商店滤梦、事件或道具对概率的影响。
- 梦境之种基础形态、苹果核等不可捕梦物品不进入计算。

| 层数 | 单次捕梦期望买入价值 | 单次捕梦期望售卖收入 |
| ---: | ---: | ---: |
| 1 | 11.40 | 5.60 |
| 2 | 16.36 | 8.15 |
| 3 | 22.07 | 11.02 |
| 4 | 27.47 | 13.73 |
| 5 | 34.30 | 17.13 |
| 6 | 36.42 | 18.19 |

结论：

- 第 1 层到第 6 层单次捕梦期望售卖收入约从 `5.60` 增长到 `18.19`。
- 增长主要来自大体积、高层核心物品进入池子，而不是层数倍率膨胀。
- 第 5 层后增长放缓，避免后期单次捕梦直接购买多个饰品。

## 道具价值补充 - 2026-05-30

道具是一次性资源，不参与背包碰撞，也不作为长期售卖资产，因此价格不再沿用普通物品的按格基准。当前道具价格带调整为：

| 稀有度 | 价格区间 | 说明 |
| --- | ---: | --- |
| 普通道具 | 5-7 | 早期补操作与低风险试用 |
| 罕见道具 | 8-10 | 流派方向或中等一次性收益 |
| 稀有道具 | 10-12 | 高影响力成长、机械、刷新类效果 |

道具投放从第 1 层第 1 个商店开始开启；第 1 层第 1 个捕梦关卡不混入道具，第 1 层第 2 个捕梦关卡开始以少量概率混入已解锁道具。商店固定结构调整为 `4 饰品 + 2 道具 + 2 物品`，并且三类商品都按当前层过滤。
