# 饰品清单 - v1.3版本

## 调整原则

- 普通饰品作为早期商店基准，价格集中在 `36-44`。
- 进阶饰品承担成型方向，价格集中在 `56-70`。
- 稀有饰品提供高上限或后期补强，价格集中在 `86-120`。
- 饰品价格不再额外套用层数倍率和稀有度倍率，价格表中的数值就是商店买入基准价。
- 14 格前期基础物品的售卖收入约为 `56`，约等于 `1.5` 个普通饰品基准价。
