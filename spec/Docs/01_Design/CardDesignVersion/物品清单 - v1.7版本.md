# 物品清单 - v1.7版本

## 梦境之种投放清理

本版对齐当前程序内的正式投放池：捕梦、商店和奖励不再投放梦境之种流派物品，也不再投放播种/升级梦境之种的道具。

`物品列表.xlsx` 同步调整：

- `梦境之种` 工作表仅保留 4 个不可捕梦的基础形态，作为运行时衍生形态记录。
- 删除 `梦境之种` 工作表中未接入正式数据的梦种流派物品。
- 从 `道具` 工作表删除小水滴、肥料包、快速发芽剂。
- 苹果蜡移除“若为苹果，额外播种”效果，只保留食物丢弃回复梦值。
